Storyboard & Reference

Download Reference
Create a natural professional model reference sheet based strictly on the uploaded character image. Use the uploaded image as the MAIN IDENTITY LOCK. Keep the same face, same facial structure, same body proportions, same skin tone, same hairstyle, same hair color, same natural expression, same age appearance, and same overall realism style. Do not beautify, redesign, stylize, or change the person. Create a clean realistic studio reference sheet on a plain light-gray or white background. Layout: Top row: 4 full-body standing views: 1. front view 2. left side profile 3. right side profile 4. back view Bottom row: 3 close-up portrait views: 1. front face portrait 2. left profile face portrait 3. right profile face portrait Character pose: Relaxed natural A-pose, arms slightly away from body, neutral calm expression, natural standing posture, bare feet or simple clean footwear if visible in the reference. Visual style: Ultra-realistic RAW DSLR photography, natural studio lighting, soft shadows, sharp facial details, realistic skin texture, realistic hair strands, accurate anatomy, clean silhouette, consistent scale, consistent head height, even spacing between panels, print-ready character model sheet. Important: Maintain perfect identity consistency across all 7 panels. Same person in every view. No extra people, no text, no logo, no watermark, no cartoon, no CGI, no fashion pose, no dramatic lighting, no exaggerated beauty retouching. Keep the same identity and same reference sheet layout, but change the outfit to: [YOUR OUTFIT DESCRIPTION].
